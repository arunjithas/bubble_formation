# --- notes ----------------------------------------------------------------
# pillow arrives with matplotlib and is what writes  --save foam.gif
# (tested 12.1.1), so it needs no entry of its own.
#
# Writing MP4 needs the ffmpeg *binary* on PATH -- it is not a pip package:
#     macOS    brew install ffmpeg
#     Debian   sudo apt install ffmpeg
#     conda    conda install -c conda-forge ffmpeg
# Without it, `--save foam.gif` still works and `python bubble_sim.py` with no
# --save opens a live window regardless.
#
# The live window also needs a GUI backend. On a headless box there is none, so
# use --save; inside a venv on Linux, `pip install PyQt5` gives you one.
